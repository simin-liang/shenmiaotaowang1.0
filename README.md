# 遗迹骑行 · Relic Ride 🛺

一款纯前端 Three.js 三车道跑酷游戏。骑上三轮车、骏马或马车，在霓虹遗迹赛道上躲避障碍、收集金币，跑得越远越好。

- **在线试玩**：[relic-ride-runner.app.workbuddy.host](https://relic-ride-runner.app.workbuddy.host/?sharecode=C5WNDAAHCM)（手机 / 电脑均可）
- **离线试玩**：下载 [`dist/relic-ride.html`](dist/relic-ride.html)，双击即可运行，无需联网、无需安装任何东西

## 玩法

三车道冲刺，按障碍颜色决定操作：

| 障碍 | 颜色 | 应对 |
| ---- | ---- | ---- |
| 矮碎石 | 🟠 橙色条纹 | 跳跃或换道（马车可直接碾碎） |
| 高石柱 | 🩷 洋红发光 | 必须换道 |
| 横梁 | 🔴 红色 | 必须下滑钻过 |
| 地面裂缝 | 🟣 紫色发光边缘 | 必须跳跃 |

### 操作

| 动作 | 键盘 | 手机 |
| ---- | ---- | ---- |
| 换道 | ← → 或 A D | 左右滑动 |
| 跳跃 | 空格 / ↑ / W | 上滑 |
| 下滑 | ↓ / S（空中按可加速落地） | 下滑 |
| 静音 | 右上角 🔊 按钮 | 同左 |

### 三种坐骑

| 坐骑 | 特点 |
| ---- | ---- |
| 三轮车 | 灵活，窄车身，中速 |
| 马 | 最快，跳得高 |
| 马车 | 最稳，车身宽，可碾碎矮障碍 |

距离超过 140 米后开始出现横梁，速度整体随距离提升，越跑越难。

## 快速开始

```bash
# 方式一：直接玩成品（推荐）
# 用浏览器打开 dist/relic-ride.html 即可

# 方式二：从源码构建
git clone <本仓库地址>
cd relic-ride
python build.py        # 重新生成 dist/relic-ride.html
```

构建脚本会把 `src/` 源码与 `vendor/three.module.js` 全部内联进一个 HTML 文件。

## 项目结构

```
├── build.py                    # 一键构建脚本（源码 → 单文件成品）
├── src/                        # 游戏源码（改这里）
│   ├── index.html              # 页面骨架（HUD / 菜单 / 结算面板）
│   ├── game.js                  # 游戏逻辑 + 3D 模型 + 碰撞 + 程序化音乐
│   └── styles.css              # 霓虹风格 UI 样式（响应式，适配手机）
├── vendor/
│   └── three.module.js         # Three.js r160（本地化依赖，离线可玩）
├── dist/
│   └── relic-ride.html        # 单文件成品（约 1.4MB，双击即玩）
└── docs/
    └── 遗迹骑行-项目说明与小白手册.docx   # 完整项目文档
```

## 技术要点

- **渲染**：Three.js + 胶囊体/球体拼装建模 + MeshToonMaterial 卡通着色，全程序化生成，无外部模型文件
- **世界**：14 块瓦片循环复用，世界整体后移实现前进，玩家恒在原点，无浮点漂移
- **碰撞**：Z 轴窗口 + 车身宽度近似 AABB；下滑时判定身高 × 0.45
- **音乐**：Web Audio 实时合成（132 BPM，Am–F–C–G 四和弦，鼓组/贝斯/琶音五声部），零音频文件、零体积开销
- **兼容**：桌面 + 移动端（触屏实时手势识别），单文件离线可玩

详细的设计思路、开发问题复盘和修改指南见 [`docs/遗迹骑行-项目说明与小白手册.docx`](docs/遗迹骑行-项目说明与小白手册.docx)。
